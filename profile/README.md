# Kasilam Digital Platforms

**Empowering township SMEs with affordable, scalable digital tools.**

Kasilam Digital Platforms is an open-source initiative dedicated to helping small and medium enterprises (SMEs) in South African townships build a professional online presence — without the high costs that usually come with it.

Many township businesses have great products and services but struggle to reach customers online due to expensive website development, branding services, and hosting fees. We solve this by providing **free, easy-to-use web templates** and **branding systems** that can be deployed on **cost-free hosting platforms** (like GitHub Pages, Netlify, or Vercel).

## Mission & Impact

- **Problem**: Township businesses often lack affordable tools for digital presence and strong branding.
- **Solution**: Scalable, customizable web templates + ready-to-use branding assets (logos, color palettes, fonts, social media kits).
- **Impact**: Enables SMEs to:
  - Create professional websites quickly.
  - Reach more customers online.
  - Build consistent, recognizable brand identities.
  - Grow their businesses sustainably.

This project is built for the community, by the community — with a focus on accessibility, simplicity, and real-world needs in South African townships.

## Features

- **Responsive Web Templates**: Mobile-first designs tailored for small businesses (e.g., spaza shops, salons, food vendors, mechanics).
- **Branding Kits**: Pre-designed logos, business card templates, social media banners, and color schemes.
- **Zero-Cost Deployment**: Step-by-step guides for free hosting (GitHub Pages, Netlify, Vercel).
- **Easy Customization**: No coding required for basic use — edit via simple HTML/CSS or use no-code tools.
- **Multilingual Support**: Templates include options for English, isiZulu, isiXhosa, and other local languages.
- **Open Source & Free Forever**: Everything is licensed under MIT — use, modify, and share freely.

## Quick Start

### For Business Owners (No Coding Needed)
1. Fork or download a template from the [templates repository](#repositories) (coming soon).
2. Customize text, images, and colors using a simple editor (we recommend VS Code or even GitHub's online editor).
3. Deploy for free:
   - [GitHub Pages guide](./docs/github-pages.md)
   - [Netlify guide](./docs/netlify.md)
4. Your site is live! Share the link with customers.

### For Contributors/Developers

2. Create a new branch (`git checkout -b feature/your-feature`).
